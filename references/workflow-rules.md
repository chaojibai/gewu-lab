# 工作流军规：读材、契约、状态门与自纠

这是**流程层**规则（怎么组织一次课件制作），与内容层规则（detail-rules 的"做得对不对"）
互补：流程保证不跳步、可追溯、**收敛**而不是无限打磨。全部来自本项目跨多门课的实践。

## 一、读材协议：观察先于推断

动工前把教材/参考材料"读干净"，按固定自下而上的顺序，不许扫一眼就写代码：

1. **物理清点**：这页出现的每件器材、每种试剂逐一列出。写"锥形瓶"之前先确认
   它确实锥形、有没有刻度、是否磨口——**不许用名字代替描述**。
2. **层次分解**：装置整体 → 部件 → 细节（宏→中→微），每层记下父子关系与连接方式。
3. **操作动词表**：通入/滴入/振荡/加热/罩上……每个动词都要有对应的物体与运动
   （与 detail-rules 第十五节"过程必须画出通路"呼应）。
4. **盲区标注**：教材没写的（背面、内部结构、具体数值）标"未知"，推测定置信度，
   不许装作确定。

三条纪律：**观察与推断分开写**（"液柱上沿在 30mL 刻度"是观察，"已滴入 20mL"是推断）；
**受控词表**（尺寸/位置/材质用可测量语言，不用"高级、漂亮"）；**按装置坐标系描述**，
不按页面阅读顺序。

## 二、质量契约先行

写第一行构建代码之前，先写下"做成什么样算合格"：

- **数学线**：读数公式、守恒关系、误差评分的定义（§5 严谨性的具体化）
- **视觉线**：每个小件"能被认出是什么"的最低标准（detail 机位清单的子集）
- **行为线**：行为探针清单与断言值（对应 `scripts/behavior_probe.js`）
- **体积线**：单文件 ≤5MB、加载 ≤2s（对应 external-assets 二）

契约是后来自纠的唯一基准："这个改动更好吗"必须对照契约回答，不凭感觉。

## 三、状态门：进度权威在文件，不在对话

对话上下文是易失的，`.courseware/state.json` 是唯一进度权威：

```bash
python3 scripts/state_gate.py init --title "酸碱中和滴定"
python3 scripts/state_gate.py next                          # 当前该做什么
python3 scripts/state_gate.py mark read-source --evidence shots/material-notes.md
python3 scripts/state_gate.py mark refine --reason "终点体积公式错了，回规格修"
```

- 每个完成步骤**必须带证据**（笔记/截图/探针输出的路径）；不适用步骤 skip 必须 `--reason`，
  禁止静默跳过。
- 修正也是步骤：`refine` 同时计入该步与全轮修正数，**步上限 3、全程上限 6**，
  超限硬停（退出码 3）——停下换方案或问人，不许无限打磨。

## 四、自纠五选一

每轮验证后，只能且必须选一个：`continue / refine-spec / refine-code / request-input / stop`。

- **refine-spec 修规格**：公式错、结构错、契约本身漏了——回规格层改完重新验证。
  **不许绕过坏规格给代码打补丁**：补丁会把"代码对、模型错"固化，越修越歪。
- **refine-code 修实现**：规格没问题，几何/材质/参数没实现到位。
- 判据顺序：先问"规格会不会是错的"，确认规格无误才动代码。

## 五、全局指标会撒谎

任何单一全局分数（整页截图相似度、平均误差、总帧率）都可能掩盖局部失败：
一个整体很像的页面，完全可以藏着"关键部件整个缺失"级别的缺陷。因此：

- 全局指标**只做初筛**；关键特征必须各有**分量断言**——终点体积单独断言、
  玻璃三件套存在性单独断言、每个小件的屏幕占比单独实测。
- **小特征要用对仪器**：整页截图看不见几像素的细节，必须放大机位或数值探针。
- 两层都要过：分量全过不代表全局像，全局过也不代表分量过。

## 六、结果透明

每轮报告改了什么（带具体数值/坐标），承认什么还不匹配；**"改进了"不许说成"完成了"**。
通过门控也不等于教学正确——严谨性（SKILL.md §5）独立验收。
