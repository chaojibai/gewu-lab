# 验证夹具与渲染诊断：让截图可信、让排查有路

外观回归（多机位）与行为回归（探针）之上的两层：**截图可不可信**（夹具稳定性）
和**坏了怎么找**（症状诊断）。全部规则在本项目课件与机械臂成品上实测过。

## 一、可复现的视觉夹具

一次截图只是一次抽样，不可复现的截图没有断言资格：

- **冻结随机源**：课件里的噪声、粒子、纹理抖动，在验证期给固定种子或临时冻结，
  否则两张"同机位"截图的差异无法归因。
- **固定成像参数**：相机机位、视口尺寸、`devicePixelRatio` 全部锁死；
  自动旋转、闪烁、缓动在截图前停到已知时刻（或直接钳制动画时钟）。
- **语义就绪，不猜时长**：等"资产解析完成 + 首帧渲染完"的确切信号
  （如加载提示隐藏、探针可读），不用固定 sleep——机器慢一倍 sleep 就失效。
- **失败也要抓**：`pageerror`、`console.error`、**网络失败请求**三路一起收。
  只看截图不看控制台，等于只验收了一半。

## 二、像素断言要留容差

不同 GPU/驱动的像素输出不可能严格一致，**跨机器的逐像素相等是伪契约**：

- 像素取样只用于粗判（这里应该是液体红、那里应该是背景灰）。
- 结构性事实用探针断言：部件存在性、包围盒投影占比、读数数值——
  这些不随驱动漂移（见 behavior_probe.js 与 workflow-rules 五）。

## 三、症状树（课件版速查）

| 症状 | 先查的证据 | 聚焦的下一步 |
|---|---|---|
| 整页黑/白 | 控制台、容器 rect、渲染计数 | 确认上下文与**非零尺寸**、渲染循环活着；用无光照材质试渲主体 |
| 器材不可见 | 包围盒、相机取景 | 手动框选包围盒看它在不在画面内；查 visibility/layers/transform 是否有限值 |
| 器材全黑 | 无光照对比 | 换 `MeshBasicMaterial` 分离"光照/环境问题"与"贴图/几何问题" |
| 全场发白 | 色彩输出链 | 查色管/输出编码是否被二次处理（r147 经典管线坑见 SKILL.md §7） |
| 解析报错但状态 200 | 实际响应内容 | `data:`URI 被 CSP 拦（零 fetch 解析，external-assets 三）；200 的 HTML 兜底页不是有效模型 |
| 局部闪烁 | 相机远近裁剪面、共面几何 | 分辨三类：深度精度（near/far 比别太大）、共面重叠（polygonOffset/抬高 0.015）、透明排序 |
| 阴影条纹/脱开 | 阴影相机覆盖、bias | 覆盖范围收紧到主体附近；bias 小步增量调 |
| 点击拾取偏移 | 视口 rect、指针坐标 | 滚动后复现；坐标必须是画布相对，不是页面相对 |
| 切步骤后场景重复 | 挂载/循环/监听器计数 | 重建场景前必须 dispose 旧几何与材质、解绑循环与监听 |
| 卡死在加载 | 网络面板、进度回调 | 逐件进度有没有在走；单件解析异常有没有兜底分支 |

## 四、无光照诊断材质（一招分家）

怀疑某件器材"发黑/看不见"时，把它**单独**换成亮色 `MeshBasicMaterial`：

- 问题跟着走（还是黑/看不见）→ 几何或变换的问题（法线、缩放、层级）。
- 问题消失 → 光照/环境/材质参数的问题（灯没照到、envMap 没生效、roughness 异常）。

一次只换一件、只关一个特性，逐步缩小；诊断用的临时材质和日志**修完必须撤干净**。

## 五、修后复验

修完不是重跑一次全绿就完事：

1. **重演原始失败动作**（同一个机位、同一个交互、同一份数据），不是挑一个顺手的用例。
2. 检查**相邻状态**——共享同一代码路径的其他步骤、其他机位、其他器材有没有被顺手改坏。
3. 验收报告三态如实：**passed / failed / not-run（带原因）**。
   "构建成功""页面能开"不能推出"性能达标、低端机可用、弱网可放"。

## 六、可达性底线（教学场景）

课件给的是学生和老师，不只给鼠标用户：

- **键盘能走完全流程**：切步骤、调参数、复位视角都要有键盘路径（我们已有 ←/→/R/Esc，
  新控件必须跟进）；焦点可见、Tab 顺序合理。
- **面板与画布同源**：控件用原生 HTML 并与 3D 状态双向同步——右侧面板天然满足，
  禁止"画布里有状态、面板显示的是另一份副本"。
- **尊重减弱动效偏好**（`prefers-reduced-motion`）：自动旋转、闪烁、装饰性运镜给开关或降级。
- **颜色不是唯一通道**：读数、状态同时用文字与形状表达（色弱可辨）。
- **兜底是 HTML**：加载失败、WebGL 不可用时给文字说明与降级路径，不是无限黑屏。
- 验收方法：**只开键盘**完整做一遍实验；触屏与缩放场景抽测。
