# 参考实现

## 直列四缸四冲程汽油机（本线样板）

| | |
|---|---|
| 交付物 | `courses/engine4-step.html`（单文件，841 KB，断网可用） |
| 源码 | `build/lessons3d/engine4-step.js` |
| 规模 | 6 步 / 80 974 三角 / 967 draw call / 0 报错 |
| 场景 | `K.envShop()` 实训车间（水泥地坪 + 工位黄线 + 压型钢板墙 + 卷帘门 + 工具柜 + 厂房顶灯） |

它示范了本技能的全部要点：

1. **实心半剖**缸体与缸盖（侧壁 + 后壁 + 剖切亮边），完整露出活塞、连杆、曲轴、气门、凸轮。
2. **孔壁**：缸套保留后半圆 + 断口壁厚棱边 + 孔口环，活塞任何行程都在"孔里"。
3. **隔板**：5 道缸间隔板，让缸体从"空架子"变成实体铸件。
4. **燃烧室**：底面板（4 缸孔）+ 后半圆凹窝 + 顶板（8 气门孔 + 4 火花塞孔），气门盘可见。
5. **真实凸轮**：极坐标挤出的桃形轮廓，鼻尖半径 = 基圆 + 升程，压在气门杆顶端。
6. **曲轴**：曲柄臂板 + 反向半圆盘平衡重 + 飞轮 + 皮带轮，曲拐相位 `[0, π, π, 0]`。
7. **机构运动**：滑块-曲柄解析解、四冲程 720° 相位、点火顺序 1-3-4-2、凸轮半速、气门升程余弦包络。
8. **拆解**：缸盖整体抬起、油底壳沿 +z 抽出放台面上（不穿台面）。
9. **交互**：悬停认件（`K.tag` + `.lab-tip`）、单击聚焦、拐角滑块、速度滑块、拆解滑块 + 一键展开。
10. **教学**：6 步 + 4 题小测，读数实时显示各缸冲程。

## 复用它

```bash
# 1. 复制骨架
cp vocational-3d/templates/lesson-scaffold.js build/lessons3d/<slug>.js

# 2. 在 build/build_chem.py 的 META / ORDER / ART 里注册 <slug>
#    职教课件记得 catalog=False

# 3. 改 buildDevice() 里的几何，改各步的 title / body / ask

# 4. 构建 + 截图
python build/build_chem.py <slug>
node build/shot-page.js courses/<slug>.html <slug> 1800
```

对照本样板时优先看三处：

- `buildBlock()` —— 半剖 + 孔壁 + 隔板的写法
- `buildHead()` —— 带孔板 + 燃烧室 + 凸轮接触
- `scene.update()` —— 曲柄连杆的姿态计算与拆解缓动
