# 交付前自检清单

> 打印出来逐条打勾。**任何一条不勾，都不算交付。**

## A. 场景身份

- [ ] 调的是 `K.envShop()`，不是 `K.envRoom()`（实验室）
- [ ] 画面里能看到**地坪**（水泥颗粒/油污）+ 工位黄线
- [ ] 台架脚垫落在地坪上（`y = groundY + .17`），设备落在台架上
- [ ] 相机俯角 ≥ .30，地面没有被台面整条裁掉
- [ ] 环境元素（墙/柜/桶/灯）不比设备亮、不比设备大、不压设备轮廓
- [ ] 后墙有构造（压型钢板竖棱为真几何 / 砖纹），不是一块纯色板

## B. 几何与剖切

- [ ] 侧壁/后壁是**实心铸件**（壁厚 0.5–0.6），只剖朝向默认机位那一面
- [ ] 每个孔都有孔壁（缸套保留后半圆 + 断口壁厚棱边）
- [ ] 腔体之间有隔板/支承壁（不是空架子）
- [ ] 剖切面有机加工亮边（高金属度薄板）
- [ ] 大平面有颗粒贴图（map + bumpMap），不是纯色塑料
- [ ] 旋转件有端盖/母线/倒角，不是一段光管
- [ ] 小件在位：螺栓、销、垫片、卡箍（提供"装配"证据）
- [ ] 所有零件**有支撑**：不悬空、不穿地、不互插
- [ ] 放大 5 倍看一遍：面接缝、z-fighting、透明排序都没问题

## C. 机构运动

- [ ] 运动由几何约束算出（曲柄连杆/凸轮相位/传动比），不是时间线
- [ ] 运动件与静止件的接触是**真的接触**（凸轮压在气门顶上、活塞在孔里）
- [ ] 角度做了卷绕（`% 720`，负数补正）
- [ ] 转速可调，能慢放到看清一个冲程
- [ ] 暂停后滑块能逐度驱动，且读数与 3D 同源

## D. 交互

- [ ] `K.tag()` 打在具体零件上，描述写"作用"（20–30 字）
- [ ] 悬停能弹出名称，网格扫描命中点 > 20 且覆盖核心零件
- [ ] 单击能聚焦（相机 tween 到该件）
- [ ] 拆解滑块与"展开/合拢"按钮行为一致，滑块值 = 3D 状态
- [ ] 拆解方向物理可行（不穿台面、不互插）
- [ ] 拆开后能看见内部结构（不留空洞）
- [ ] 标注 `onTop: true`，且按步骤分组（不是全开）
- [ ] 只用键盘（←/→/R/Esc）能走完全流程

## E. 工程

- [ ] `python build/build_chem.py <slug>` 构建通过
- [ ] `node build/shot-page.js …` 输出 `NO-ERRORS`
- [ ] 三角 ≤ 55 万、draw call ≤ 1200、单文件 ≤ 1.2 MB
- [ ] 硬件 GPU 下 ≥ 55 fps（`--use-angle=d3d11`）
- [ ] 四机位都看过：默认 / 正面平视 / 俯视 / 侧视
- [ ] 改的是 `build/lessons3d/<slug>.js`，不是 `courses/*.html`
- [ ] 职教课件在 META 里 `catalog=False`（不进化学目录）
- [ ] 页面上写明了模型简化与假设（不让学生当实测数据）

## F. 教学

- [ ] 每步有 `ask`（引导问题），且能从模型上验证
- [ ] 六步结构完整：总览 → 机构 A → 机构 B → 循环 → 拆解 → 测验
- [ ] 读数由模型计算，不是拟合曲线
- [ ] 测验题有 `why`，解释"为什么"而不只是答案
- [ ] 教材定位（`tb`）写对：哪个专业、哪门课、哪一章
