# 05 · 交互与教学结构

职教课件的交互只有四个目的：**认零件、看装配、看运动、自测**。不要为了"能交互"加无意义的旋转和特效。

## 1. 认零件：`K.tag` + 悬停提示

```js
K.tag(mesh, '活塞', '承受燃烧气体压力，把往复运动经连杆传给曲轴');
```

- 引擎在 `pointerup`（位移 < 6px 才算点击）调 `pickAt()`，沿 `userData.tag` 向上找父级。
- 悬停显示 `.lab-tip`（`名称 · 作用`），单击 `focusOn(obj)` 把相机 tween 到该件包围盒。
- **拾取只看 `world.children`**，所以设备必须挂在 `K.world()` 下（`scene.setup` 里第一行取根节点）。

写法要点：

- `tag` 打在**具体零件 mesh** 上，描述写"它干什么"，不写"它是什么"。
- 一个总成（缸盖、曲轴）可以打在整个 Group 上，但内部关键件（活塞、气门、凸轮）要单独打，否则学生只能认到总成级。
- `desc` 控制在 20–30 字，`.lab-tip` 是一行提示，长了会被截。

## 2. 看装配：拆解状态机

```js
apply: function (s) { s.spin = 0; s._labSet = 'none'; s.explPct = 0; },
controls: [
  { type: 'range', key: 'explPct', min: 0, max: 100, step: 2, label: '拆解程度（%）' },
  { type: 'btn', label: '展开 / 合拢', onClick: function (s) { s.explPct = s.explPct > 5 ? 0 : 90; } }
]
```

```js
/* update 里自己缓动（不要依赖引擎的状态补间去驱动 transform） */
O.ex += ((s.explPct / 100) - O.ex) * Math.min(1, dt * 6);
var ex = O.ex * O.ex * (3 - 2 * O.ex);            // smoothstep
headAsm.position.y = HEAD_LIFT * ex;              // 缸盖抬起
panAsm.position.set(0, -.06 * ex, PAN_DROP * ex); // 油底壳沿 +z 抽出（不是往下沉）
```

三条硬规矩：

1. **滑块与 3D 必须同源**。滑块的值是 `s.explPct`，那就别再让补间去改 `s.explPct`，否则滑块显示 0 而模型已经抬起。
2. **拆解方向物理可行**：螺栓件沿装配方向抽出；重件（油底壳、盖板）**不能往下沉**——会穿过工作台，改成沿 +z/+x 抽出来放台面上。
3. **拆开后不留空洞**：缸盖抬起后要能看到燃烧室、气门、活塞顶；油底壳抽出后要能看到曲轴箱与曲轴。

推荐的拆解层级（整机 → 总成 → 分件）：

```
0%   整机
30%  气门室盖/外罩抬起（露出配气机构）
60%  缸盖抬起（露出燃烧室、活塞顶）
90%  油底壳抽出 + 缸盖再抬（露出曲轴、连杆大头、主轴承座）
```

## 3. 看运动：控件必须成对

| 控件 | 类型 | 说明 |
|---|---|---|
| 暂停 / 继续 | btn | 单键切换 `s.spin` |
| 运转速度 | range 0–3 | 慢放看冲程 |
| 曲轴转角 | range 0–720 | 暂停后逐度拖，读数同步 |

**读数的自洽**：面板读 `values(s)`，其中角度用 `s.theta` 换算成 0–720°，各缸冲程用 `strokeOf(betaOf(theta, i))`。读数与 3D 必须来自同一组函数，不能一个用 `theta` 一个用滑块值。

## 4. 六步教学结构（职教设备课的通用骨架）

| 步 | 名称 | 干什么 | 机位 | 控件 |
|---|---|---|---|---|
| 1 | 整机总览 | 三大块分工 + 全局结构 | 3/4 全景 | 暂停、速度 |
| 2 | 核心机构 A（曲柄连杆） | 运动如何转换 | 半身近景 | 转角滑块、自动运转 |
| 3 | 核心机构 B（配气） | 时序如何配合 | 正面平视 | 暂停、速度 |
| 4 | 工作循环（四冲程） | 四缸相位与读数 | 全景 | 暂停 + 读数 |
| 5 | 拆解总览 | 装配关系、密封/定位 | 略高全景 | 拆解滑块、展开/合拢 |
| 6 | 小测验 | 3–4 题，随机抽 | 全景 | — |

每步都有 `ask`（引导问题）——面板顶部醒目显示，这是"迷思先行"的抓手。

## 5. 标注（spriteLabel）

```js
O.labels = {
  block:  K.spriteLabel([-11.2, y0 + 3.4, 3.4], '缸体 / 缸套', { w: 4.8, fs: 40, onTop: true }),
  piston: K.spriteLabel([-7.6,  y0 + 6.0, 3.2], '活塞 ×4',     { w: 3.4, fs: 40, onTop: true })
};
```

- **`onTop: true` 必须开**：否则实心墙板会把标签文字切掉半截（`depthTest:false` + `renderOrder:60`）。
- **按步骤分组显示**（`s._labSet = 'all' | 'crank' | 'valve' | 'none'`），不要 8 个标签一次性糊上去。
- 拆解状态（`ex > .02`）时全部隐藏，避免标签飘在空中。
- 标签锚点在设备**外侧**，`z` 给正值（靠近相机），别压在零件上。

## 6. 测验题怎么写

好题的三个特征：**有唯一正确答案、能从模型上验证、错选项是真实误区**。

```js
{ q: '直列四缸四冲程发动机，曲轴转一圈（360°）内，共有几个缸完成做功？',
  opts: ['2 个', '1 个', '4 个', '0 个'], ans: '2 个',
  why: '每 180° 有一个缸做功，360° 内正好两个缸做功。' }
```

题库 3–4 题随机抽，`why` 必须解释**为什么**，不能只说"答案是这个"。

## 7. 键盘可达性

引擎已支持 `←/→` 换步、`R` 重置视角、`Esc` 关提示。**只用键盘要能走完全流程**（这是课件进教室的硬要求，投影笔通常只有翻页键）。
