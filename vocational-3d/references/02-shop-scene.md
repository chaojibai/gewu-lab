# 02 · 实训车间场景基准（`K.envShop`）

## 为什么必须先定场景

设备的"身份"由场景决定。同一台四缸机：

- 放在化学实验室（白墙 + 绿黑板 + 内凹试剂窗 + 环氧实验台）→ 一眼假，学生不会信这是实训设备；
- 放在车间（水泥地坪 + 工位黄线 + 压型钢板墙 + 卷帘门 + 工具柜 + 厂房顶灯）→ 身份立刻成立。

**这是最早、最廉价、最容易漏的一步。** 先调场景，再建模型。

```js
K.envShop({ groundY: -15.5 });   // groundY 必须与台架脚垫对齐
```

`envShop` 会自动隐藏默认的淡墙与试剂窗（`BGREF.wall / BGREF.wins`），与 `K.envRoom()` 互斥、可重复调用。

## 元素表（一层都不能少）

| 层 | 实现 | 参数基准 | 常见错误 |
|---|---|---|---|
| **地坪** | 水平 `PlaneGeometry` + Canvas 贴图（水泥颗粒 + 机油渍径向渐变 + 裂纹折线），`repeat 16×12` | 250×180，`roughness .88`、`metalness .03` | 没有地面 → 台架悬空；纯色地面 → 像纸 |
| **工位黄线** | 4 条贴地细长平面，`y = groundY + .02` | 线宽 0.55，色 `0xd9b33e` | 与地面同高 → z-fighting 闪烁 |
| **后墙** | 底板平面 + **竖棱用真 Box 几何**（间距 ≈ 4 世界单位） | 底板 `0x39434d`，棱 `0x424c56`，棱 0.92×H×0.5 | 只用贴图伪造波纹 → 近景糊；棱太亮 → 读成百叶窗 |
| **墙裙** | 下半墙深色带 + 黄色分界压条 | 裙高 9、压条 0.5×0.5 | 全白墙 → 无围合感 |
| **侧墙** | 砖纹 Canvas 贴图（砖缝 + 随机色差），`repeat 7×4` | 色 `0x8b8078`，`roughness .92` | 两侧都空白 → 转视角就露馅 |
| **卷帘门** | 12 条横向瓦楞 Box + 2 导轨 + 顶箱 + 底梁 | 门 44×34，条厚 0.9 | 画成一块平板 |
| **工业高窗** | 天空底板 + 玻璃 + 钢窗框（4 边 + 十字梃）+ 窗台 | 单扇 17×13，位置 ±24/±46 | 也摆到卷帘门位置上 |
| **工具柜** | 柜体 + 4 抽屉面板 + 拉手，靠后墙 | 13×15×9，色 `0x1c2f3e` | 悬在台子后面（不在墙边） |
| **洞洞板** | 板 + 挂着的扳手（杆 + 圆头） | 板 20×11，扳手 6–8 长 | 扳手做得比活塞还长 |
| **油桶** | 圆柱 + 两道箍 | r 3.1、高 9.2 | 摆到工位通道中间 |
| **顶** | 厂房桁架 2 根 + 工业吊灯（灯罩 + 自发光灯盘 + PointLight）+ 横贯镀锌管 | 桁架 `groundY+56`，灯 `groundY+45` | 灯放太低 → 画面上缘出现"黑三角" |

## 三条硬规矩

### 1. 地面必须入画

透视关系：台面越高、台面越大、相机越低，地面越容易被台面挡死。

| 参数 | 安全值 | 症状 |
|---|---|---|
| `pitch`（俯角） | **.30–.32** | < .25 时台面把地面整条裁掉 |
| `dist` | 40–48 | 太小 → 只剩台面；太大 → 设备太小 |
| 台面尺寸 | 设备宽 + 12～15 | 台面 46×27 时地面全被挡；32×19 才露得出来 |

改完机位先看一眼"画面里有没有地坪 + 黄线"，没有就继续调，别急着看设备。

### 2. 设备是主体

环境元素只做两件事：**给身份**、**给尺度**。

- 亮度不要超过设备：墙/地压暗，设备保持高光。
- 尺寸不要超过设备：工具柜 15 单位、油桶 9 单位这种量级。
- 位置不要压住设备轮廓：背景元素集中在设备后方 45° 之外。

### 3. 深色在这套管线里压不住（重要）

r147 经典管线 + 后处理终合是**双重 gamma**：`FinalShader` 已经做了 `pow(col, 1/2.2)`，renderer 又按 sRGB 输出。

结果：`color: 0x131f1b`（近黑绿）渲染出来约等于**浅灰绿**。把 hex 一路调到 `0x050a08` 也没用，只会在纯黑附近突然塌陷。

正确做法：

- **不要用"深色"表达暗部**，用**材质差异**表达：金属（`metalness .85 / roughness .3`）、涂装（`metalness .3 / roughness .55`）、橡胶（`metalness .05 / roughness .9`）、铸件（`metalness .8 / roughness .44` + 颗粒贴图）。
- 需要整体更暗，调终合曝光，比逐件改色有效：

```js
// scene.update 里，等 composer 建好后一次性压曝光
var CP = window.__labDebug.composer;
CP.passes.forEach(function (p) {
  if (p.uniforms && p.uniforms.uExposure) p.uniforms.uExposure.value = .74;   // 默认 .9
});
```

## 光照基线（车间）

```js
K.envShop();
K.scene().traverse(function (o) {          // 车间比实验室暗，环境光收一档
  if (o.isHemisphereLight) o.intensity *= .58;
  else if (o.isDirectionalLight) o.intensity *= .86;
});
/* 剖切内部补光：从 +z 前方斜打进来，否则缸内发黑、活塞看不清 */
var fillIn = new T.DirectionalLight(0xffffff, .62); fillIn.position.set(6, 12, 22);
var fillIn2 = new T.DirectionalLight(0xdfe8ff, .28); fillIn2.position.set(-12, 6, 18);
K.scene().add(fillIn); K.scene().add(fillIn2);
```

剖切件的内部（缸孔、曲轴箱、气门室）没有任何直接光，**必须补正面斜光**，否则一片死黑，学生会以为模型缺件。

## 台架：别用化学实验台

素养线的 `K.bench()` 有挡水槽和试剂架，是**实验室身份**，职教不能用。本线的工装台：

```js
/* 深色环氧/涂装台面 + 金属包边 + 前缘黄警示条 + 方管腿 + 脚垫 + 下部工具柜 */
var top  = RM(32, 1.6, 19, .28, MAT.benchTop);  top.position.y = -.8;
var band = RM(33.2, .55, 20.2, .16, MAT.bench); band.position.y = -1.72;
var warn = RM(32.3, .22, .34, .06, MAT.warn);   warn.position.set(0, -.06, 9.45);
```

三条细节决定"像不像设备台"：

1. **台面必须有颗粒贴图**（`map` + 可选 `bumpMap`），纯色大平面近景必糊。
2. **前缘有黄警示条**，这是车间工位最便宜的身份符号。
3. **台下有东西**：工具柜、隔板、横梁。空心的四条腿看起来像折叠桌。

重型设备（发动机、变速箱）更适合**矮翻转架**：4 只脚轮 + 短腿 + 两根立柱夹住耳轴，可以绕轴翻转，比台面更专业。

## 反例对照

| 现象 | 原因 | 修法 |
|---|---|---|
| 设备像浮着 | 没有地坪，或地坪高度与脚垫不齐 | `K.envShop({ groundY })`，脚垫 `y = groundY + .17` |
| 车间感没有 | 相机俯角 < .25，地面被台面裁掉 | `pitch .30–.32`，台面缩小 |
| 墙像百叶窗 | 竖棱太亮/太宽/间距太大 | 棱 `0x424c56`、宽 0.92、间距 4 |
| 台面惨白 | 双 gamma 把深色抬亮 | 改材质（金属/颗粒），或压 `uExposure` |
| 画面上缘有黑三角 | 吊灯太低、灯罩背面朝相机 | 灯抬到 `groundY+45` 以上，灯罩加 `emissive` |
| 背景比设备抢眼 | 墙面/柜子太亮太大 | 压暗环境色，环境件退到 45° 之外 |
