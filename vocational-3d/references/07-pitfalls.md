# 07 · 本线专属坑表（全部踩过）

按"症状 → 原因 → 解法"查。前 12 条是几何/视觉，13 之后是工程与流程。

## 几何与剖切

| 症状 | 原因 | 解法 |
|---|---|---|
| 活塞、连杆、曲轴像浮在半空 | 外壳用了全透明（`opacity .15`）或不透明缸套挡住了 | 改成实心半剖 + 缸套只保留后半圆（`thetaStart = π/2, thetaLength = π`, `DoubleSide`） |
| 整机读成"空架子/铁丝笼" | 腔体之间没有隔板 | 加缸间隔板（主轴承座上方那道铸件壁），5 道 |
| 活塞中位四周什么都没有 | 只画了孔口圆环（Torus），没画孔壁 | 加半圆缸套 + 两片断口壁厚棱边 |
| 气门盘（蘑菇头）看不见 | 气门座坐在缸体上表面，活塞顶到缸盖只剩 0.2 缝 | 缸盖底面抬到 `DECK+.40`，中间留 0.65 的燃烧室，气门盘坐进去 |
| 缸盖读成一圈墙 | 没有底面/顶面板 | `plateGeo` 加"4 个缸孔"的底面板 + "8 气门孔 + 4 火花塞孔"的顶板 |
| 凸轮悬在气门杆上方 0.2–0.3 | 桃形鼻尖半径没算升程 | `鼻尖 = 基圆 + MAXLIFT`；气门杆顶落在基圆下缘 |
| 凸轮像个"球插在圆盘上" | 用球+圆柱拼的 | 极坐标 `Shape` + `ExtrudeGeometry` 挤出真桃形 |
| 曲轴平衡重插进曲轴箱底板 | 平衡重半径 > 轴到底板的距离 | 平衡重 r ≤ 1.2、底板降到 `BLOCK_BOT+.5`；或整体抬曲轴 |
| 飞轮啃到缸体侧壁 | 飞轮 `x` 落在侧壁厚度区间内 | 主轴加长，飞轮移出侧壁（本例 `x = -8.9`，侧壁到 -8.2） |
| 剖切面像纸片 | 侧壁厚度 < 0.3，且没有机加工亮边 | 壁厚 0.5–0.6 + 剖切面贴 0.16 厚高金属度亮条 |
| 大平面像塑料板 | 纯色无纹理 | canvas 噪声当 `map` + `bumpMap`（铸铁麻点），`repeat 5` |
| 铸件上一道道竖纹 | 给没有 uv 的几何挂了 `normalMap` | 去除 normalMap，或改用有 uv 的 `BoxGeometry` |

## 场景

| 症状 | 原因 | 解法 |
|---|---|---|
| 设备摆在化学实验室桌上 | 直接调了 `K.envRoom()`（实验室身份） | 职教一律 `K.envShop()` |
| 设备像浮着 | 没有地坪，或地坪高度与脚垫不齐 | `K.envShop({groundY})`，脚垫 `y = groundY + .17` |
| 车间感没有 | 俯角 < .25，地面被台面整条裁掉 | `pitch .30–.32`；台面缩到"设备宽 + 14" |
| 墙像百叶窗 | 竖棱太亮/太宽/间距太大 | 棱 `0x424c56`、宽 0.92、间距 4 |
| 台面惨白（深色压不住） | 双重 gamma（FinalShader 的 `pow(1/2.2)` + renderer sRGB） | 靠材质区分而非深 hex；整体更暗改 `uExposure = .74` |
| 画面上缘出现黑三角 | 吊灯太低、灯罩背面朝相机 | 灯抬到 `groundY+45` 以上，灯罩加 `emissive` |
| 背景抢眼 | 环境中元素比设备亮/大 | 压暗环境色，环境件退到设备后方 45° 外 |
| 拆解时油底壳穿过台面 | 拆解方向往下 | 改成沿 +z 抽出，落回台面 |

## 工程

| 症状 | 原因 | 解法 |
|---|---|---|
| `ReferenceError: PI is not defined` | `kit3d.js` 里**没有** `PI/TAU` 常量（那是 lesson 里的） | 引擎文件内一律写 `Math.PI` |
| 页面全白、控制台零报错 | `dt` 在 `setup()` 里被用到 | 动态逻辑全搬到 `update(dt, s)` |
| 滑块显示 0 但模型已转到 600° | 滑块值和补间目标不同源 | 滑块驱动的量同时写初值（`s.theta = 0; s.setAng = 0;`） |
| 读数显示补间中间值 | 面板读了 `s[key]` 而不是 `s[key + 'T']` | 读数统一读 `*T` |
| 标注文字被切掉半截 | sprite 参与深度测试，被实心墙挡住 | `K.spriteLabel(..., { onTop: true })` |
| 悬停点不亮 | 设备没挂在 `K.world()` 下，或 `K.tag` 打在了 `world` 外 | setup 里 `var G = K.world()`，所有件 `G.add(...)` |
| 改了 `courses/*.html` 又变回去 | 直接改了产物 | 改 `build/lessons3d/<slug>.js`，重新构建 |
| `build_chem.py` 里改不动（Edit 报 "String to replace not found"） | 文件是 CRLF | 用 Python `read_text()` 读写，或匹配时保留 `\r` |
| 补丁打进去后 `SyntaxError` 在奇怪的位置 | Python 字符串里 `\n` 写成了字面 `/n` | 用 `assert a in s` 先校验，再 `replace`，最后 `node -e` 验语法 |
| 构建产物里出现"化学·探究实验"标签 | 职教课没排除在化学目录外 | META 加 `catalog=False`，并让 `build_catalog()` 跳过 |
| 三角/帧率超红线 | 车间环境与设备细分叠加 | 环境 ≤ 3 千三角；旋转体 `seg 16–24`；螺栓/齿用克隆共享材质 |

## 流程

| 症状 | 原因 | 解法 |
|---|---|---|
| 反复调材质越调越假 | 跑在 SwiftShader 软渲染上 | 换 `channel:'chrome'` + `--use-angle=d3d11` |
| 只看正面图就交付 | 俯视/侧视没看 | 至少四机位：默认/正面平视/俯视/侧视 |
| 标注互相压 | 8 个标签同时显示 | 按步骤分组（`all / crank / valve / none`） |
| 学生看不出重点 | 没有 `ask` 引导问题 | 每步写一个"为什么"的问题，面板顶部展示 |

## 一条经验

**所有"看起来不对"的问题，先问三个问题：**

1. 这个东西**有没有支撑**？（悬空 = 接触/孔壁/底座缺失）
2. 它**在什么场景里**？（身份错 = 场景模板用错）
3. 它**是被什么光照亮的**？（死黑 = 剖切内部没补光）
