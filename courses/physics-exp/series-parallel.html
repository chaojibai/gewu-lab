探究类课标 4.2.11

探究串联电路和并联电路中电流、电压的特点

类别：探究类 册次：九上 章节：第十四章 第二节（电流规律）、第四节（电压规律）
主要器材：电流表、电压表、灯泡、导线（另需电源、开关）

一、实验目的

  • 通过实验得出串、并联电路中电流与电压的规律；
  • 串联：I = I₁ = I₂，U = U₁ + U₂；并联：I = I₁ + I₂，U = U₁ = U₂；
  • 巩固电表接法与多位置测量的方法。

二、实验原理

串联电路：电流处处相等（I = I₁ = I₂）；总电压等于各用电器电压之和（U = U₁ + U₂）。
并联电路：干路电流等于各支路电流之和（I = I₁ + I₂）；各支路两端电压相等且与电源电压相等（U = U₁ = U₂）。

三、实验器材

电流表、电压表、灯泡、导线（另需电源、开关）

四、实验步骤

  • 1连接两盏灯串联电路，将电流表分别接入 A、B、C 三点（如图），测各处电流；
  • 2用电压表分别测每盏灯两端电压 U₁、U₂ 及总电压 U；
  • 3改接为两盏灯并联电路，电流表测干路与各支路电流 I、I₁、I₂；
  • 4电压表测各支路电压 U₁、U₂ 及电源电压 U；
  • 5换用不同规格灯泡重复，归纳规律。

五、数据记录与处理

六、注意事项与误差分析

  • 电流表串联、电压表并联，接线“+”“−”不可接反；
  • 多次换用不同规格灯泡，避免“特殊值”误导（如两灯完全相同时易误以为并联各支路电流相等是普遍规律）；
  • 测电压时电压表可直接接电源两端。

七、教学要点与易错点

  • 易错点：并联电流规律误记为“各支路相等”（仅在两支路电阻相同时偶然成立）；
  • 概念：节点法与回路法分析电路；
  • 拓展：家庭电路是并联，用电器互不影响；节日小彩灯部分是串联。
