探究类课标 4.2.9

探究通电螺线管外部磁场的方向

类别：探究类 册次：九下 章节：第十八章 电与磁 第二节 电生磁
主要器材：螺线管、电源、小磁针、铁屑（另需导线）

一、实验目的

  • 认识通电螺线管外部磁场与条形磁铁相似；
  • 会用小磁针判断磁场方向，并用右手螺旋定则（安培定则）判定极性；
  • 理解电流方向改变时磁场方向随之反向。

二、实验原理

通电螺线管外部磁场分布与条形磁铁相似，两端为 N、S 极。
右手螺旋定则（安培定则）：右手握螺线管，四指指向电流方向，大拇指所指一端为N 极。

三、实验器材

螺线管、电源、小磁针、铁屑（另需导线）

四、实验步骤

  • 1在硬纸板上绕制（或用现成）螺线管，固定在桌面上，撒少许铁屑，轻敲纸板使铁屑排列显示磁感线；
  • 2通电后观察铁屑分布，对照条形磁铁磁场；
  • 3在螺线管两端放置小磁针，根据小磁针 N 极指向判断该端是 N 极还是 S 极；
  • 4改变电源正负极（电流方向），观察小磁针与铁屑分布的极性是否反向；
  • 5用右手螺旋定则验证所判极性。

五、数据记录与处理

电流方向小磁针指北端靠近的一端该端极性
方向 A记录S / N
反向后记录反向

六、注意事项与误差分析

  • 铁屑只是显示磁场分布，不能指示方向，方向须用小磁针判定；
  • 改变电流方向，磁场方向反向（N、S 极互换）；
  • 安全：低压电源，避免短路，接线牢固。

七、教学要点与易错点

  • 易错点：安培定则四指与拇指含义混淆（四指电流、拇指 N 极）；
  • 概念：奥斯特实验（电生磁）是电流磁效应的开端；
  • 拓展：电磁铁、电磁继电器、奥斯特实验与通电螺线管的联系。
